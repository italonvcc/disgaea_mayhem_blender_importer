Addon to import Disgaea mayhem models and animations to blender



* ONLY tested in blender 5.2.1 LTS
* Highly untested. Expect issues.
* \[IMPORTANT] You will need to extract the model\_1\_00.dat file using quickbms fafullfs sctript to get the .nmbm files



Install Instructions:



* Download ZIP from releases
* In Blender go to Edit > Preferences > Addons > install form disk > Select the zip file 



Using:



* In blender go to File > Import > Disagea Mayhem
* Select the .nmbm character model
